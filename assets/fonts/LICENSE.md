# Bundled fonts

Both faces are subset (latin) variable builds served locally so the site
makes no third-party requests.

- **Bricolage Grotesque** — SIL Open Font License 1.1.
  Mathieu Triay. Variable axes: opsz 12–96, wdth 75–100, wght 200–800.
  Used for display headlines, labels, dates and navigation.
  <https://github.com/ateliertriay/bricolage>
- **Newsreader** — SIL Open Font License 1.1.
  Production Type, for Google. Variable axes: opsz 6–72, wght 200–800; roman
  and italic. Used for prose and publication titles.
  <https://github.com/productiontype/Newsreader>
