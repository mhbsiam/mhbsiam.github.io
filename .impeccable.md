# Impeccable context — mhbsiam.github.io

Full visual system (tokens, components, do/don't) lives in `DESIGN.md`.
Product context lives in `PRODUCT.md`. This file is the short version that
every design session should read first.

## Design Context

### Users
Personal academic portfolio of Md Hasanul Banna Siam, PhD candidate in
Cardiovascular Immunology (Tyrrell Lab, UAB Heersink School of Medicine).
Visitors are principal investigators, potential collaborators, hiring
committees and fellow scientists. They arrive from a talk, a conference
conversation or a paper lookup, usually on a laptop, and want to answer four
questions fast: who is this, what do they research, what have they published,
how do I reach them. Register: brand (the design is the product).

### Brand Personality
Warm, credible, curious. First-person copy with a human voice ("Hi, I am
Siam." / "Say hello.") set inside an austere, editorial frame so the warmth
comes from the words, not from decoration. Emotional goals: confidence and
calm; the page should feel like a well-kept record, never a pitch.

### Aesthetic Direction
- **Concept: "Ink plate."** A plate from an anatomy atlas: deep blue-black
  ground, chalk type, hairline rules, one chartreuse mark that always points
  at the thing that matters. Sections are numbered Plate I–VIII. The CAFE
  software feature is the single inverted "positive print" band on light
  paper. This direction is settled; future work extends it, not replaces it.
- **Theme:** dark only. Not a dark mode; a printed dark plate. No glow, no
  neon, no light variant.
- **Type:** Bricolage Grotesque (variable; condensed 75–84% width for
  display, 100% for uppercase labels) and Newsreader (variable roman +
  italic) for prose. Self-hosted in `assets/fonts/`.
- **Colour:** OKLCH only, defined once in `css/tokens.css`. Tinted blue-black
  ink `oklch(16% 0.022 262)`, warm chalk `oklch(94% 0.012 90)`, chartreuse
  `oklch(87% 0.19 118)` as the only chromatic colour on ink. Olive
  `oklch(42% 0.13 122)` stands in for chartreuse on the light band. Never
  pure black or white.
- **Structure:** hairlines and type do the structuring. Ledgers, reference
  lists, quadrants and tables; no cards, pills, chips or icon-above-heading
  grids. Plate numbers stack above titles, never beside them.
- **Motion:** one hero page-load reveal, one live WebGL UMAP figure, 160ms
  colour transitions. Nothing scroll-driven. `prefers-reduced-motion`
  collapses everything.
- **Anti-references:** glowing "techy" developer portfolios, WebGL scroll
  narratives, sterile clinical aesthetics, gradient text, glassmorphism,
  AI-slop card grids, multi-accent channel systems, generic SaaS heroes.

### Design Principles
1. **Calm over spectacle.** One figure, one reveal, no scroll-jacking. If an
   animation can be removed without losing information, remove it.
2. **Content is the design.** The record (publications, appointments) carries
   the page; rules and type serve reading. Never wrap content in boxes.
3. **One mark, used sparingly.** Chartreuse appears only where it points at
   something: the cluster, the current section, a first-author credit, a
   focus ring. If it shows up more than a handful of times per viewport,
   something is wrong.
4. **Accessible by default.** WCAG 2.2 AA on every colour pair (dimmest label
   grey is 5.4:1 on ink), 46px touch targets, visible instant focus rings,
   semantic HTML with one h1 per page, no horizontal scroll from 320px up.
5. **Zero-build simplicity.** Plain HTML/CSS/JS served from the repo root on
   GitHub Pages. No dependencies, no third-party requests, no raw colour
   values outside `tokens.css`.
6. **Honest content.** No invented DOIs, dates, metrics or testimonials. Link
   a publication title only when a DOI exists.
